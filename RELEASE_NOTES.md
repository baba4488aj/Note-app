# Lumenwild 0.11.0

- Every ordinary animal now has its own innate passive. Discover healing splashes, regeneration sharing, leftover-shield recycling, emergency protection, conditional damage, and more. Custom pets inherit an ordinary passive; Legends retain theirs.
- Choose one talent for each pet at account levels **25, 50, and 75**. Role and element paths offer different builds, including lifesteal, overhealing shields, stronger reactions, burn immunity, cooldown rewards, and last stands. Open **Stats & abilities → A path of their own**.
- Swap or reset talent choices for free. Talents use no skill slots and apply to the next encounter.
- Set smarter auto-training goals: stop after a number of battles, at an account level, or after any/specific new item drop. Completed encounters collect rewards before the session stops.
- Session counters now include wins, defeats, draws, XP, recruits, and item drops, with a clear reason when a goal stops training.
- Existing saves preserve account progress, pets, builds, gear, and tower clears. Talent choices and training settings save automatically. Reload leaves auto-training stopped.

Installed Windows copies download this update automatically. Open **Saves → Game updates → Check for updates**, then choose **Restart & update** when ready, or close the game to install after saving.

The Windows installer is unsigned. Existing desktop saves and pre-update backups remain in your Windows profile.
